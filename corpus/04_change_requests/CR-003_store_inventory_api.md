# Change Request CR-003 – Store Inventory Availability API

|---|---|

## Description
Add a real-time store inventory availability API so the e-commerce storefront can show "available for pickup today" at each of the 340 stores. The API will expose stock levels from the new order management platform with a target response time of under 300 milliseconds at the 95th percentile.

## Justification
Buy-online-pick-up-in-store (BOPIS) orders grew 31% last year, and the current storefront relies on an overnight batch file that is often out of date, causing cancelled pickups.

## Impact
- **Cost:** $85,000 (WS4 budget increases from $800,000 to $885,000).
- **Schedule:** No milestone impact; delivered within existing WS4 sprints.
- **Resources:** One additional API developer for 10 weeks.

## Approval
Approved by the Client Program Director under the delegated authority for CRs below $100,000 with no milestone impact.
