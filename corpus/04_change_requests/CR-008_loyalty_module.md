# Change Request CR-008 – Loyalty Program Module Integration

| Field | Value |
|---|---|
| CR ID | CR-008 |
| Requested by | Jessica Park, Director of Marketing, Northwind Retail Group |
| Date raised | 2026-03-16 |
| Workstream | WS4 – Integration & APIs |
| Status | Rejected at SC-04 on 2026-03-25 – deferred to Phase 2 |

## Description
Integrate the Northwind Rewards loyalty platform with the new order management system so loyalty points are earned and redeemed in real time at checkout, instead of through the nightly batch.

## Impact assessment
- **Cost:** $410,000 (estimate).
- **Schedule:** Approximately 6 additional weeks of build and test, which would push go-live past 2026-08-17 and close to the November 15 retail freeze.
- **Scope:** Loyalty platform changes are explicitly out of scope in the program charter.

## Decision
The Steering Committee rejected the CR for Phase 1 because it would put the re-planned go-live at risk and add cost while WS2 is already over budget. The request is deferred to Phase 2, with a business case due by 2026-06-30.
