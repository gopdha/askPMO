# ADR-001: Front end: React SPA over a FastAPI API

- **Status:** Accepted
- **Date:** 2026-10-03
- **Source:** Architecture views deck and HLD (decision register)

## Context
Options considered: Streamlit (PRD v1); React SPA over a FastAPI API.

## Decision
React SPA + FastAPI.

## Rationale
Matches the OnePulse pattern; the under-the-hood panel needs custom UI, and a real API serves the SPA, eval runner and future agents alike.

## Consequences
More code than Streamlit; PRD FR-19 updated accordingly.
