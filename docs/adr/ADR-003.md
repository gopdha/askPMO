# ADR-003: Session model: platform auth

- **Status:** Proposed
- **Date:** 2026-10-03
- **Source:** Architecture views deck and HLD (decision register)

## Context
Options considered: Token in the browser; platform auth with a cookie session.

## Decision
Container Apps built-in auth (Entra ID) on Azure; no sign-in locally.

## Rationale
No token ever reaches browser code, and there is no session code to write or secure.

## Consequences
Local runs never exercise auth; sign-in is tied to Container Apps.
