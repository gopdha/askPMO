# ADR-004: Chat path is synchronous

- **Status:** Proposed
- **Date:** 2026-10-03
- **Source:** Architecture views deck and HLD (decision register)

## Context
Options considered: Queue-coordinated like OnePulse runs; synchronous request.

## Decision
Synchronous request; the queue is reserved for ingestion.

## Rationale
A user is waiting about 6 s and there is nothing to survive a restart; queueing would add polling with no gain.

## Consequences
Long requests hold a replica; a 30 s timeout caps it.
