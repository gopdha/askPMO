# ADR-005: Orchestration with LangChain (LCEL)

- **Status:** Accepted
- **Date:** 2026-10-03
- **Source:** Architecture views deck and HLD (decision register)

## Context
Options considered: Hand-rolled Python; LlamaIndex; LangChain (LCEL).

## Decision
LangChain (LCEL), versions pinned.

## Rationale
Ready components for history-aware queries and structured output, and auto-instrumentation for Arize tracing.

## Consequences
Fast-moving APIs (v1 moved retrievers to langchain-classic); versions pinned and stages covered by tests.
