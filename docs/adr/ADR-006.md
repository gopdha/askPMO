# ADR-006: Retrieval index behind one interface

- **Status:** Proposed
- **Date:** 2026-10-03
- **Source:** Architecture views deck and HLD (decision register)

## Context
Options considered: Qdrant everywhere; AI Search everywhere; Qdrant local + AI Search on Azure.

## Decision
IndexBackend protocol: Qdrant locally, Azure AI Search on Azure.

## Rationale
Qdrant runs free in Docker with dense + sparse vectors; AI Search is managed, uses Managed Identity, and needs no stateful container.

## Consequences
Two backends to maintain; a golden-set parity run (P7 gate) is required before cutover.
