# ADR-008: Reranking in-process with bge-reranker-base

- **Status:** Proposed
- **Date:** 2026-10-03
- **Source:** Architecture views deck and HLD (decision register)

## Context
Options considered: AI Search semantic ranker; hosted rerank API; in-process cross-encoder.

## Decision
BAAI/bge-reranker-base inside the api process, model baked into the image.

## Rationale
Identical behavior locally and on Azure, scores visible per chunk, no extra service cost.

## Consequences
CPU latency for 30 pairs; larger api image; api keeps min 1 replica on Azure.
