# ADR-009: Embeddings from Foundry in both environments

- **Status:** Proposed
- **Date:** 2026-10-03
- **Source:** Architecture views deck and HLD (decision register)

## Context
Options considered: Local bge-small; Foundry embedding deployment.

## Decision
Foundry embedding deployment everywhere.

## Rationale
One embedding model keeps indexes and eval results comparable between local and Azure.

## Consequences
Local development needs network access and a key; small per-token cost.
