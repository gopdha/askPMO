# ADR-010: PostgreSQL as the application database

- **Status:** Proposed
- **Date:** 2026-10-03
- **Source:** Architecture views deck and HLD (decision register)

## Context
Options considered: SQLite; PostgreSQL.

## Decision
PostgreSQL 16 (container locally; Flexible Server on Azure).

## Rationale
Chats, feedback, document registry, ingest status and eval runs need concurrent writers from three services.

## Consequences
One more service to run locally.
