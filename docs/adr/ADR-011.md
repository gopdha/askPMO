# ADR-011: Queue-driven ingestion worker

- **Status:** Accepted
- **Date:** 2026-10-03
- **Source:** Architecture views deck and HLD (decision register)

## Context
Options considered: CLI script; in-process background task; queue-coordinated worker.

## Decision
Queue worker: Azurite locally, Storage Queue with KEDA on Azure.

## Rationale
Same code path in both environments; ingestion never blocks chat; crash-safe retries; scale to zero on Azure.

## Consequences
An extra container and a job-status model to maintain.
