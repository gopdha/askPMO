# ADR-012: Tracing with Arize AX

- **Status:** Accepted
- **Date:** 2026-10-03
- **Source:** Architecture views deck and HLD (decision register)

## Context
Options considered: Arize Phoenix (PRD v1); Arize AX.

## Decision
Arize AX via OpenTelemetry (OpenInference instrumentation).

## Rationale
Same platform as OnePulse; traces every LLM call and stage; stores eval runs as experiments.

## Consequences
External dependency and the only egress path on Azure; real corpora would need span masking.
