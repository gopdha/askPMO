# ADR-013: YAML configuration profiles

- **Status:** Proposed
- **Date:** 2026-10-03
- **Source:** Architecture views deck and HLD (decision register)

## Context
Options considered: Hard-coded settings; YAML profiles.

## Decision
Profiles baseline, hybrid, rerank, full, with per-request toggle overrides.

## Rationale
UI toggles and eval runs both map to profiles, so an experiment is a config change, not a code change.

## Consequences
Profiles need schema validation (Pydantic).
