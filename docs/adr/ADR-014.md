# ADR-014: Deployment: local first, Azure target

- **Status:** Accepted
- **Date:** 2026-10-03
- **Source:** Architecture views deck and HLD (decision register)

## Context
Options considered: Local only; Azure only; local now with Azure target.

## Decision
Docker Compose locally for version 1; Azure Container Apps as the target state (P7).

## Rationale
Fast, free iteration locally; the same images and contracts carry to Azure.

## Consequences
Azure-specific adapters and IaC are deferred to P7.
